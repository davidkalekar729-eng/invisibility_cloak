# Invisibility Cloak & Spider-Man Mask Overlay

Real-time computer vision application using OpenCV and MediaPipe.

## Project Structure
├── cloak.py
├── face_landmarker.task
├── haarcascade_frontalface_default.xml
├── spiderman_mask.png
└── README.md

## Prerequisites & Setup
1. Install Python on your system.
2. Install required packages:

bash
pip install opencv-python mediapipe numpy

## How to Run
bash
python cloak.py
Save the file by pressing Ctrl + S.
